TECHNICAL DETAILS
================================================================================

Backend (PHP/Laravel):
────────────────────
• Updated Methods:
  - getHotSellingItems() - Accepts staff_id, customer_id
  - getHotCustomers() - Accepts staff_id, customer_id
  - getSummaryStats() - Accepts staff_id, customer_id

• New Methods:
  - getCustomers() - Returns {id, name} for all customers
  - getStaffMembers() - Returns {id, name} for all staff

• Query Logic:
  - Base filters: branch_id, isDeleted, quotation_status
  - Date range: BETWEEN from_date AND to_date
  - Staff filter: created_by = $staffId OR staff_id = $staffId
  - Customer filter: user_id = $customerId

Frontend (HTML/CSS/JavaScript):
──────────────────────────────
• UI Elements:
  - Staff select dropdown (id="staffFilter")
  - Customer select dropdown (id="customerFilter")
  - Styled with matching CSS

• JavaScript Functions:
  - loadStaffMembers() - AJAX to populate staff
  - loadCustomers() - AJAX to populate customers
  - Updated getDateRange() - Includes filter values
  - AJAX calls pass staff_id and customer_id

• Event Handlers:
  - Page load → Load dropdowns + data
  - Apply Filters → Collect filters + load data
  - Tab switch → Show filtered results

Database:
─────────
• Queries Optimized For:
  - users.branch_id (indexed)
  - orders.branch_id (indexed)
  - orders.user_id (indexed)
  - orders.staff_id (indexed)
  - orders.created_at (indexed)

• Data Retrieved:
  - Customers: WHERE role='customer' AND isDeleted=0
  - Staff: WHERE role IN (...) AND isDeleted=0
  - Sales: WHERE quotation_status='sales' AND isDeleted=0
